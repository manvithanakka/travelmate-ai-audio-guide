# ✈️ TravelMate AI – Personalized Audio Travel Guide

TravelMate AI is an AI-powered travel companion designed to make exploring destinations more informative, engaging, and convenient. It transforms destination names into personalized travel stories and converts them into audio narration, allowing users to discover the history, culture, landmarks, and interesting facts of places around the world.

## 🌍 Overview

With TravelMate AI, users can enter any destination, select their preferred narration language, choose the length of the guide, and generate an AI-powered travel description with audio narration. Whether planning a visit or learning about a famous landmark, users can explore destinations through an interactive and personalized experience.

## ✨ Key Features

- **Destination-Based Guides:** Generate travel information by entering a destination name.
- **AI-Powered Content Generation:** Use Google Gemini AI to create informative and engaging descriptions.
- **Flexible Guide Length:** Choose between a quick summary for a brief overview and a detailed story for a more comprehensive exploration.
- **Multilingual Narration:** Select from supported languages, including English, Hindi, Tamil, and Telugu.
- **AI Voice Narration:** Convert generated travel descriptions into spoken audio using Murf AI.
- **Voice Customization:** Select a supported narration voice and locale for a personalized listening experience.
- **Audio Playback:** Listen to the generated travel guide directly on the website.
- **Downloadable Audio:** Download the generated narration as an MP3 file when supported by the backend response.
- **Simple User Interface:** Generate and listen to travel guides through an easy-to-use web interface.

## ⚙️ How It Works

1. **Enter a Destination:** Type the name of a place, monument, city, or tourist attraction.
2. **Choose a Language:** Select the preferred language for the travel guide.
3. **Select Guide Length:** Choose a quick summary or a detailed story based on your interest.
4. **Customize the Voice:** Select a supported AI voice and narration locale.
5. **Generate the Travel Story:** The Flask backend sends the request to Gemini AI to generate destination-related content.
6. **Convert Text to Audio:** The generated description is sent to Murf AI for speech synthesis.
7. **Listen and Explore:** Read the travel description and play, pause, or download the generated audio using the available controls.

## 🛠️ Technologies Used

- **HTML5** – Structures the web application.
- **CSS3** – Provides the visual design and responsive layout.
- **JavaScript** – Handles user interactions and communication with the backend.
- **Python and Flask** – Process requests and connect the frontend with AI services.
- **Google Gemini AI** – Generates destination descriptions and travel stories.
- **Murf AI** – Converts text into natural-sounding audio narration.

## 🎯 Project Objective

The main objective of TravelMate AI is to make travel information easier to explore through personalized storytelling and audio narration. It combines generative AI and text-to-speech technology to provide an engaging digital tour-guide experience without requiring a traditional human guide for every destination.
